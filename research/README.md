This folder holds the user research for the project.

### `user-study.md`

This file contains the user study work. It includes the survey, user responses, personas, and user stories. This helps us understand who we are building the app for and what problems we are trying to solve.

### `miro-board.md`

This file contains the link to the miro board during our initial research and brainstorming phase, looking at user reviews of existing meme generators (pros and cons), looking at the design of meme generator apps, among other factors.

### `ADRs.md`

This file contains our ADRs for prioritized features and the reasonings behind it.
