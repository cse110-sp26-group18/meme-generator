## Project Overview

Our project is a meme generator that is meant to make creating and editing memes faster, easier, and less annoying. A lot of meme generators already exist, but many of them feel clunky, especially when users are trying to quickly edit text or make something on their phone.

---

## Versions

The most updated version of the app is stored in `meme-app/`. 

A new version is pushed to main every week, after sprint meeting review on Sunday. 

Previous versions can be found on the different branches, named `vx` where x is the version number.

## Repo Organization

This repo is organized so that people can understand both the project idea and the different versions of the app.

The main folders are:

- `meme-app`
- `documentation`
- `research`
- `testing`

The `meme-app` is the most updated version of the app. 

The `documentation` folder is for project planning, goals, workflow, screenshots, and AI usage logs.

The `research` folder is for user research, survey information, personas, and user stories.

The `testing` folder is for unit and E2E tests.

## Instructions to Run MemeMaxing

1. Access website:
   - Open the deployed page on either desktop or mobile [here](https://cse110-sp26-group18.github.io/meme-generator/meme-app/)

2. Get started

   a. Upload
   - If you have a meme template saved, or from another source, you can click the “upload” button on desktop, or the + button on mobile. You can alternatively Drag and Drop a supported image type on the desktop.

   b. Browse Meme Library
   - If you do not have your own template, you can browse our library for the most popular memes (refreshed every 30 days to keep the most relevant memes). By clicking on any of the memes, you can start editing.

   c. AI-Mode
   - If you have no idea of the type of meme you would want to make, you can click on the “AI Mode” button to turn it on.
   - By filling out the prompts according to your situation and the link to generate a free Gemini API key, you can click “generate” to have our AI agent populate meme ideas

3. Start Editing

   - No matter the strategy used to select an image, you now have an image you can freely edit
   - You can add your own captions, customizing their position, size, and font style. You can also edit the AI-generated captions if the AI mode was used.

4. Save

   a. Download/Share
   - On Desktop, you can download your final meme to your device
   - On Mobile, you can click the share button to share/download your meme, however you would like.

   b. Copy
   - On all devices, there is also a clipboard button on the top-right-hand side of the meme that allows you to quickly copy the final meme to the clipboard and paste it in any group chat, social media, or other platforms you would like. This is ideal if you do not want to download the meme and want a quick means of sharing it.
