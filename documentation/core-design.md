# Project Overview

Our project is a meme generator that is meant to make creating and editing memes faster, easier, and less annoying. A lot of meme generators already exist, but many of them feel clunky, especially when users are trying to quickly edit text or make something on their phone.

The main idea for our app is that users should be able to upload an image, click directly on the image to add, edit, and position the text, and then download or copy the finished meme. We also want users to be able to choose from a small meme template library if they do not already have an image they want to use.

Since memes are usually made and shared quickly in group chats, social media, and conversations, our focus is on speed and ease of use. We do not want the user to feel like they are using a complicated editing app just to make one joke.

---

## Core Design Goals

### 1. Direct Text-on-Image Editing

One of our main priorites is making text editing feel natural. Instead of having the user type text into a separate box outside the image, we want the user to click directly on the image and add text exactly where they want it.

After the text is placed, the user should still be able to move it, resize it, and edit it. This is important because meme editing should feel quick and flexible, not clunky and determinate.
---

### 2. Mobile-Friendly and Responsive Design

We want the app to work well on different screen sizes, especially phones. A lot of memes are made and sent while people are already texting, scrolling through Instagram, or talking in group chats, so the app needs to feel usable on mobile.

The app should work on:

- Desktop
- Tablet
- Phone

We aim to build a the website to be responsive enough that feels smooth and usable on small and large screens.

---

### 3. Upload Image or Choose a Meme Template

Users have two simple ways to start making a meme. They should be able to upload their own image ot choose from a template library.

For the first version, we want to keep the template library small, around 10–20 templates. This keeps the app from feeling overwhelming while still giving users enough options to start with.

Later on, the library can grow into something bigger with categories, emotions, characters, or search features.

---

### 4. Simple Text Editing Tools

The first version should include the basic text tools for meme editing. Instead of overloading the editor with too many options, we aim to provide enough customization to make the meme readable and funny.

Text tools we want to include:

- Font selection
- Text color
- Text border or outline
- Background highlight
- Bold and italic options
- Resizable text

The default meme font is Impact because it is used most often. Other included fonts wil be Arial, Comic Sans, Helvetica, and Montserrat.

---

### 5. Download and Copy/Paste Support

After the user finishes a meme, they should be able to save or share it easily through download or copy and paste.

Copy and paste is important because memes are usually shared quickly. If someone has to download every meme before sending it, this adds friction and slows down the process.

Downloading will still be an option as users may want to save memes for later or upload them somewhere else.

---

## AI Features Being Considered

We are interested in adding AI features, but we want to make sure the basic meme editor works first. AI could make the app more useful, but only if it actually makes the process faster and easier instead of adding more confusion.

Some AI features we are considering are:

- Generating meme captions on blank images
- Changing existing meme captions
- Changing facial expressions or visual features
- Making text from existing memes editable
- Creating motion in memes

These features will be tested and re-evaluated after our main priorities are accomplished.

---

## Planned Meme Template Library

The first meme library will be small and easy to browse to prevent paradox of choice.

The template library may include:

- Popular meme formats
- Popular characters
- Emotion-based categories
- Recognizable reaction images

In the future, we could organize templates by character or emotion. For example, a user could click on a character and then see different emotional versions of that character, such as confused, angry, excited, or disappointed.

This would help users who know the feeling they want to express but do not know the exact name of the meme.

---

## Design Philosophy

The main design goal is to make meme creation feel quick and low-effort.

Our app should focus on:

- Speed
- Simplicity
- Easy sharing
- Fun and recognizable meme formats
- A casual editing experience

The app does not need to feel overly polished at first. A slightly messy or low-quality meme style can actually fit the meme culture better, as long as the editor itself is easy to understand and use.

---

## Current Priority List

Right now, these are the features we care about the most in order of priority:

1. Direct text-on-image editing
2. Responsive design for different screen sizes
3. Upload image support
4. Download and copy/paste support
5. Basic text customization tools
6. Small meme template library
7. Popular character or emotion-based template organization
8. AI caption or text-editing features
9. Video/GIF support
10. Social sharing and audio features
